功能

围绕 .desktop 文件全生命周期的一组克制而完整的能力。

⌖

多路径扫描

扫描用户目录、系统目录与 flatpak 导出目录，遵循 XDG union 语义，自动标注覆盖关系。

✎

双视图编辑

表单编辑常用字段，源码视图直改原文；未识别字段（本地化 Name、Desktop Actions）原样保留。

✚

模板新建

模板向导生成新启动项，固定写入用户目录，不污染系统配置。

⛨

删除即备份

删除前自动备份到 ~/.local/share/desktop-manager/backup/，随时可手动恢复。

⚿

系统文件只读

/usr/share 下的文件不直接改写，引导复制到用户目录做 union 覆盖，避免提权风险。

⚛

原子写入

主进程统一文件 IO，原子写入 + 备份，渲染进程经 contextBridge 通信，contextIsolation 全程开启。

安装

从 GitHub Releases 下载 deb 包，一条命令完成安装。

deb sudo dpkg -i deepin-desktop-manager_*_amd64.deb
apt sudo apt-get install -f

运行时依赖 libnotify4；deb 包已声明。
